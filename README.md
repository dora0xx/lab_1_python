# Консольный набор утилит, калькулятор и конвертер величин

## Что умеет проект?
- посчитать выражение
- конвертировать из одной величины в другую
- перевести выражение в постфиксную запись
- показать подсказку

## Основные команды

- calc - считает поданную на вход строку
- convert - конвертирует различные величины
- postfix - перевести выражение в постфиксную запись
- --help - выводит справку(краткую информацию)


## calc
калькулятор\
команда позволяет посчитать выражение с использованием знаков +-*/, приоритет операций учитывается, скобки не учитываются!!!

операции с унарным - и + также успешно обрабатываются

**Использование**

```
python -m toolkit calc "ВЫРАЖЕНИЕ"
```

выражение которое нужно посчитать требуется вводить в кавычках

## convert
команда позволяет перевести совместимые величины из одной единицы измерения в другую

поддерживаются такие величины как:\
Масса\
Температура\
Длина

**Использование**
```
python -m toolkit convert ЗНАЧЕНИЕ --from ИЗ_КАКОЙ_ВЕЛИЧИНЫ --to В_КАКУЮ_ВЕЛИЧИНУ
```

ввод температуры ниже абсолютного нуля считается некорректным и приводит к ошибке

## postfix

**перевод выражения в обратную польскую запись**
```
python -m toolkit postfix "ВЫРАЖЕНИЕ"
```
## help

```
python -m toolkit calc --help
python -m toolkit convert --help
python -m toolkit --help
```

## Установка проекта ##
В качестве пакетного менджера в проекте используется uv,\
проверить версию uv:\

```console
uv --version
```

**если у вас не установлен uv:**\
**macOS / Linux:**

```commandline
curl -LsSf https://astral.sh/uv/install.sh | sh
```

**windows:**
```commandline
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```
- git clone https://github.com/dora0xx/lab_1_python.git
- cd lab_1_python
- uv sync
- source .venv/bin/activate

далее можно запускать программу
